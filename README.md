### NeuroPedal

**Machine Learning for Guitar Effects**

A machine learning project that predicts guitar pedal drive and tone settings from audio recordings. Built with Python and PyTorch, using a ResNet34 model to analyze mel spectrograms and estimate pedal settings.

**Key Features**

- Continuous drive and tone predictions

**Technologies:** Python, PyTorch, ResNet34

### Visual Breadth-First Search

**Algorithms & Interactive Visualization**

A visual implementation of the breadth-first search algorithm using Python and Pygame. The application lets users create walls on a grid, select a target, and watch the algorithm explore possible routes from the starting point to the destination.

**Key Features**
- Interactive 25 × 25 grid
- User-defined walls and target position
- Visual exploration of visited and queued cells
- Reconstructed path when the target is reached

**Technologies:** Python, Pygame, Graph Algorithms

[**View Repository →**](https://github.com/Quinnsmitth/BreadthFirstSearch)
